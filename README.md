# wechat-assistant

个人自用的微信助手工具集，两个技能：

| 目录 | 作用 | 平台 |
|------|------|------|
| `mac-wechat-assistant/` | 微信内容自动提取（待办/日程/干货/热点/技术），推送飞书 | macOS |
| `windows-wechat-decrypt-0.2.0/` | 微信 4.x 聊天记录解密、查询、导出 | Windows |

## 使用

- **Mac 助手** → `mac-wechat-assistant/README.md`
- **Windows 解密** → `windows-wechat-decrypt-0.2.0/WINDOWS_README.md`
