# WeChat Decrypt for Windows

适用于 Windows 微信 4.x 数据库解密的工具（仅限本人已登录账号）。

## 功能

- 从已登录微信进程提取数据库密钥
- 解密 `MSG*.db`、`MicroMsg.db` 等聊天数据库
- 导出聊天记录、联系人、媒体文件等
- 支持命令行 + Web 界面

完整使用说明请查看 **[WINDOWS_README.md](WINDOWS_README.md)**

密码学实现细节：[WINDOWS_ALGORITHM.md](WINDOWS_ALGORITHM.md)

## 快速开始

详细步骤请参考 `WINDOWS_README.md`。

## 注意事项

- 仅供个人数据导出使用
- 不要用于他人账号
- 项目不包含任何真实聊天数据或密钥
